# Мир по кусочкам

Детская игра-пазл с наклейками и книгой сюжетов. Студия Prosto Slozhno Games.

Играть онлайн: https://gohsa04071988-glitch.github.io/mir-po-kusochkam/

Вся игра — один файл `index.html`: скачай и открой в браузере. Интернет нужен только при первом запуске.

## Установить как приложение (телефон, планшет)

Открой сайт в Chrome и в меню браузера (⋮) выбери «Установить приложение». Появится иконка «Пазлы», игра откроется на весь экран, без адресной строки, и будет работать без интернета.

## Что внутри

- 8 миров: Поезд, Гонки, Стройка, Земля, Животные, Динозавры, Космос, Море
- В каждом мире 7 этапов: от 4 до 48 деталей — всего 56 пазлов
- 168 наклеек трёх редкостей (обычные, редкие, золотые)
- Книга сюжетов: 8 историй, финальный свиток сказки после 48-го пазла
- У каждого мира своя музыка; звук и музыку можно выключить кнопками
- Управление мышью или пальцем, вся игра помещается в экран телефона (v2.1)
- Прогресс сохраняется в браузере автоматически
